Complete Module-wise Curriculum

Structured learning from foundation to practical implementation and career preparation.

01

Advanced Excel

  • Data cleaning and validation
  • IF, IFS and logical functions
  • Lookup functions: XLOOKUP, INDEX-MATCH
  • PivotTables, charts and dashboards
  • Power Query and data modelling
  • Macros and VBA fundamentals
02

SQL for Data Analysis

  • Database and table fundamentals
  • SELECT, filtering and sorting
  • Joins, subqueries and set operators
  • GROUP BY, HAVING and aggregate functions
  • CTEs and window functions
  • Views, procedures and business queries
03

Power BI

  • Power Query transformations
  • Data modelling and relationships
  • DAX measures and calculated columns
  • Time intelligence and KPI design
  • Interactive dashboards and drill-through
  • Power BI Service, sharing and RLS
04

Python for Analytics

  • Python fundamentals and data structures
  • NumPy and pandas
  • Cleaning, merging and reshaping data
  • Exploratory data analysis
  • Matplotlib and Seaborn visualization
  • Excel and reporting automation
05

Statistics

  • Descriptive statistics
  • Probability and distributions
  • Sampling and confidence intervals
  • Hypothesis testing and ANOVA
  • Correlation and regression
  • Business interpretation of results
06

AI Tools & Career Preparation

  • Generative AI for analysis
  • Prompting for Excel, SQL and Python
  • Portfolio and GitHub guidance
  • Resume and LinkedIn optimization
  • Mock interviews and aptitude practice
  • Final capstone presentation
