Data Analytics Course Curriculum

Practical modules covering the tools and analytical skills used for reporting, BI and data analyst roles.

  • Advanced formulas and lookup functions

  • Data cleaning and validation
  • Power Query and dashboard concepts

Module 2: SQL for Data Analytics

  • SELECT, filtering and aggregations
  • Joins and subqueries
  • CTEs, functions and views
  • Practical database analysis

Module 3: Power BI

  • Power Query and data transformation

  • DAX calculations and KPIs

Module 4: Python for Data Analytics

  • Interpreting data for business decisions

  • AI-assisted data workflows
  • Analysis and reporting support
